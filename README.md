# EK Collection

Database-free Next.js storefront with WhatsApp order requests. Products are configured in `src/lib/catalog.ts` (initially empty; do not publish fictitious items). Add verified product data and images under `public/products/`. Configure `NEXT_PUBLIC_WHATSAPP_NUMBER` on Vercel as international digits without `+` and redeploy before accepting orders. Orders are only sent as prefilled WhatsApp messages; the customer must press Send in WhatsApp. There is no database, Payload admin panel, order persistence, or payment processing. The cart is stored in the customer's browser. Confirm availability, payment and delivery manually.
